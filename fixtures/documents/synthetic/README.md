# Synthetic invoice fixtures (issue #237)

Every file in this folder is **fictitious** — generated by
`scripts/generate-synthetic-invoice-pdfs.py`, seeded (`random.seed(42)`) so
the output is reproducible. No real supplier, customer, invoice or amount
appears here.

`invoice_index.csv` carries the ground-truth fields (issuer, recipient,
invoice number, date, currency, net/VAT/gross, and a `quirks` tag) for each
PDF, for use in `src/domain/extraction/syntheticFixtures.test.ts`.

## What this is for

Deterministic test fixtures for the extraction/OCR **pipeline mechanics**:
real PDF bytes across several visual layouts, a credit note, a foreign
currency reverse-charge purchase, a pro-forma, a statement of account, and
two degraded "scanned" image-only PDFs that force the OCR code path.

## What this is *not* for

This is **not** the real, anonymised invoice test set requested in #202
(tracked, before removal, as #218 §J). Do not:
- use any figure here as evidence for a real VAT return or journal entry;
- match one of these files against a real bank transaction;
- count these toward the real anonymised document set #202 asked for.

See #237 for the full context and #218 for why that distinction matters.
