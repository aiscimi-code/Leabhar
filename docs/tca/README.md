# TCA 1997 — Tier 2 extracts

There is **no LRC revised Act** for the Taxes Consolidation Act 1997. eISB only publishes the **1997 as-enacted** section pages. Inserted sections (s.600F/J/M/P, s.835D/DA) are not at `/eli/1997/act/39/section/…`.

## How to use these files

1. Read the as-enacted section here.
2. Overlay the later Finance Act that amends it (FA 2024 Act 43 is already in `docs/statutes/2024-act-43/`).
3. Do not treat 1997 text as current law where a later FA substituted it.
