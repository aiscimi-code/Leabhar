# Customs Manual on Import VAT — full official PDF

35 pages, last updated May 2026. Binding hooks remain VATCA s.3(b) and s.53A + SI 734/2020 reg.14A.

Charge: goods imported from outside the EU. Not services. Union goods from another Member State are ICAs, not import VAT, unless not in free circulation.

Collection generally follows customs treatment (temporary importation, transit, temporary storage, customs warehouse, inward/outward processing). A customs-duty relief does not by itself relieve import VAT.

Postponed accounting: live C&E + VAT registration; account on the VAT3 (PA1 value; VAT in T1 and, if deductible, T2).
