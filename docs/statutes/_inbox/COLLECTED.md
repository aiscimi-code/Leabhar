# #218 inbox — what is here

Official downloads under `docs/statutes/_inbox/<letter>/`, exactly as downloaded
(PDF or saved HTML), each with a Markdown conversion beside it (see
`CONVERSION.md`). Each folder's `SOURCES.txt` gives the URL and retrieval date.
`MANIFEST.sha256` records the SHA-256 of every file, so any file can be
re-checked against the bytes that were collected (AGENTS.md #5).

unpacked from its archives unchanged).
