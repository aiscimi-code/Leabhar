# Income Tax and Corporation Tax (Relevant Contracts Tax) Regulations 2011 (S.I. 651/2011)

The eRCT regulations — puts the RCT deduction-authorisation workflow on
ROS. Read alongside [`docs/statutes/rct/`](../rct/) (TCA ss.530/530A, the
RCT TDMs) — this SI is the mechanics of *how* RCT is administered, not the
charge itself.
