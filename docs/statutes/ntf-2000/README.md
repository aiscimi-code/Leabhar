# ntf-2000

National Training Fund Act 2000 s.4, LRC revised (retrieved 2026-09-27): the 1.0% levy on reckonable earnings, paid by the employer and collected with PRSI. The .html keeps note F3, which dates the 1.0% rate from 1 January 2020.

`src/domain/rules/payrollIngestion.ts` (EPIC 20, issue #526). Each provision
the payroll rules quote is an exact slice of the Markdown here.
