# FRS 102 — pointer only, not the standard text

FRS 102 is Financial Reporting Council copyright. `frs-102.md` in this
folder links the official edition and lists which sections govern which
accounting decisions (capitalise vs. expense, revenue timing, leases,
provisions) — it does not, and must not, quote or paste the standard's
text. Schema rank: `accounting_standard`, below `legislation` — never
outranks VATCA, TCA, or the Companies Act 2014.
