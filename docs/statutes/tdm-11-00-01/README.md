# tdm-11-00-01

Revenue Tax and Duty Manual Part 11-00-01, *Cars: capital allowances and lease/hire payments* (last reviewed November 2019). The PDF is kept in the rules catalogue, beside its entry `catalogue/tdm-11-00-01/11-00-01.json`, which the knowledge base loads (#556). Guidance, not law. It is quoted for the 2008 CO2 scheme (§6): group 1 up to 155g/km, group 2 up to 190g/km. That scheme applies to car expenditure from 1 July 2008 to 31 December 2020, and the Notes for Guidance on Part 11C no longer set it out.

Extracted by `npm run catalogue:extract -- tdm-11-00-01/11-00-01`, which slices §6 from the PDF's text with the markers in `src/domain/rules/carEmissionsCuration.ts` (issue #466).
